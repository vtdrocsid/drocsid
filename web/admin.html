Public address

Required: a public https address with a valid certificate that anyone on the internet can reach. Discord loads the player from it (each Discord app's Activity URL Mapping) and sends people back to it after Sign in with Discord (the OAuth2 redirect), so creating a bot and signing in only work with a real public address. A LAN address, an IP or plain http won't work.

Poster cache

Posters are saved in /data so pages load fast and survive restarts. Every night at 2:00 AM, every library that's turned on is refreshed: new titles are ready before anyone browses, changed artwork is picked up, and posters unused for a week are removed.

Super admins

Super admins can change everything in every server, including libraries, Live TV and connections (Discord bots and media servers). Admins of a single server are set in Access by server. Owners were set during setup and can't be removed here.
